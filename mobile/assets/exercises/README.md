# Exercise artwork

These transparent exercise illustrations were generated for Full Body with OpenAI's built-in image generation tool on 2026-09-28. They are original project assets. Every exercise in the catalog has its own local image, so the picker does not bundle third-party photos, remote trackers, or misleading movement stand-ins.

The shared prompt requested a premium semi-realistic instructional sports illustration, an anatomically plausible athletic adult, charcoal clothing with restrained electric-lime accents, a transparent background, and no text, logos, or watermarks. Each asset prompt then specified the exact movement, equipment, body position, and framing for its catalog entry.
